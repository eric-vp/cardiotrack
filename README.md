# CardioTrack

### Um aplicativo Java para registrar e armazenar medições cardíacas.

<img src="https://drive.google.com/file/d/1GN9q00k9ycbRSLEvL9xBMg-aAFAIq97C/view?usp=drive_link" alt="CardioTrack">

## Funcionalidades

- Captura e armazena medições cardíacas.

- Salva os registros em um arquivo local.

- Exibe medições anteriores.

## Tecnologias Utilizadas

- Java (Swing para interface gráfica)

- Manipulação de arquivos com FileWriter e BufferedReader

## Exemplo de Uso

Ao registrar uma nova medição, os dados são armazenados em um arquivo medicao.csv criado na área de trabalho. Cada nova medição será adicionada ao final do arquivo.
